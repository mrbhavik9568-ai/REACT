# session4 React App

This project is a minimal React app scaffold. It includes a small `convert.js` script to convert and resize an image to WebP using `sharp`.

Quick setup:

1. Install dependencies:

```
npm install
```

2. Place your original PNG inside `src/assets/` named `food-scooter.png`, or adjust the path in `convert.js`.

3. Convert the image (creates `food-scooter.webp`):

```
npm run convert-image
```

4. Start the dev server:

```
npm start
```
