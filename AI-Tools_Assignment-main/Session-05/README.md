# Session5 — Electronics Store (Vite + React)

Minimal scaffold created with Vite + React.

Setup:

```bash
cd session5
npm install
npm run dev
```

Open the dev server at the address printed by Vite (typically http://localhost:5173).

Files of interest:
- [session5/index.html](session5/index.html)
- [session5/src/App.jsx](session5/src/App.jsx)
- [session5/src/components/ProductDescription.js](session5/src/components/ProductDescription.js)

Add `images/pizza.jpg` to `session5/images/` to see the SEO image example.
